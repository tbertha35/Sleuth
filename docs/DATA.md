# Training data: what to use, and is it OK to use?

You don't have a corpus yet, so this is the plan, from "works today with no
downloads" up to "enough for a 350M–1B model". Licence and terms notes were
checked in October 2026 (sources at the bottom). **I'm not a lawyer.** Personal,
non-commercial learning, with the data and models kept on your own machines,
is the lowest-risk use there is. If you ever publish a model or a dataset, re-check
the terms for that use.

Nothing here is downloaded automatically. Every download is your call.

---

## Stage 0: synthetic data (now; zero terms-of-service risk)

```bash
python -m sleuth synth --mb 50       # -> data/raw/synthetic/{story,math,code}.jsonl
```

Generated by `sleuth/forge/data/synthetic.py` from templates in this repo, so no
third-party text is involved. It has three categories on purpose (simple stories,
arithmetic, tiny Python functions), so the analyzer can show category-specific
neurons. It's narrow: a model trained on it is fluent only inside that little world.
Use it to prove the pipeline and to learn the tools.

## Stage 1: TinyStories (approved as next, 2026-10-23; ~10M–30M models)

Short children's stories written by GPT-3.5/GPT-4, from the paper *TinyStories:
How Small Can Language Models Be and Still Speak Coherent English?* (Eldan & Li, 2023).
It's the standard dataset for exactly the model sizes of Milestone 1: a ~10M model
trained on it writes coherent little stories.

- **Licence:** CDLA-Sharing-1.0 (on the dataset card). Its sharing ("share-alike")
  obligations concern redistributing the *data*. The licence defines *Results*
  (outputs of computational use, which must not contain more than a trivial part
  of the data) separately from the data. Training locally is the use it's built for.
- **The GPT-generated part:** OpenAI's terms forbid *OpenAI's customers* from using
  outputs to build competing models. That contract bound the dataset's authors, not
  you, and a personal learning model isn't a competitor. It's also one of the most
  widely used research datasets. I consider it fine for this project. If you'd rather
  avoid model-generated text entirely, skip to the public-domain sources below.
- **Format:** plain `.txt`, stories separated by `<|endoftext|>` lines, which our
  ingest reads natively. Use the GPT-4-only "V2" files (higher quality):
  `TinyStoriesV2-GPT4-train.txt` (~2 GB) and `TinyStoriesV2-GPT4-valid.txt`.

On your machine (this is the download; your decision):
```bash
mkdir -p data/raw/tinystories && cd data/raw/tinystories
curl -LO https://huggingface.co/datasets/roneneldan/TinyStories/resolve/main/TinyStoriesV2-GPT4-train.txt
curl -LO https://huggingface.co/datasets/roneneldan/TinyStories/resolve/main/TinyStoriesV2-GPT4-valid.txt
cd ../../..
python -m sleuth tokenizer --input data/raw/tinystories --vocab-size 8192 --max-mb 500
python -m sleuth shard --input data/raw/tinystories --tokenizer data/tokenizers/tinystories-8192.json --out data/shards/tinystories
python -m sleuth train configs/tinystories-10m.toml
```
The same in Windows PowerShell (`curl.exe`, because plain `curl` there is an alias for
a different command, and `mkdir` needs no `-p`):
```powershell
mkdir data\raw\tinystories; cd data\raw\tinystories
curl.exe -LO https://huggingface.co/datasets/roneneldan/TinyStories/resolve/main/TinyStoriesV2-GPT4-train.txt
curl.exe -LO https://huggingface.co/datasets/roneneldan/TinyStories/resolve/main/TinyStoriesV2-GPT4-valid.txt
cd ..\..\..
```
then the three `python -m sleuth ...` lines exactly as above.
(We'll make our own validation split by hashing documents, so the two files can
simply sit together; the `-valid` file is extra held-out data.)

## Stage 2: real, varied text (125M and up)

A 125M model wants ~2.5B tokens (~10 GB of text); 350M wants ~7B (~28 GB). Options,
best first:

| Source | Licence / terms | Format | Notes |
|---|---|---|---|
| **FineWeb-Edu** (HF, "sample-10BT" subset ≈ 10B tokens) | ODC-By 1.0; use is *also* subject to Common Crawl's terms of use | **Parquet** | The best-quality open web text for small models (educational-quality filtered). Needs `pyarrow` to read Parquet, a new dependency that needs your OK. Attribution is required if you redistribute the data. The underlying web pages keep their own copyrights; training on Common Crawl derivatives is standard research practice, but legally unsettled in some jurisdictions. |
| **Wikipedia** (dumps.wikimedia.org) | CC BY-SA (and GFDL); attribution + share-alike when you *redistribute* | XML `.bz2` | ~20 GB of English text, clean and factual. Needs a wikitext→text cleaner, which we can write with the stdlib. |
| **Project Gutenberg** | Books are public domain in the US. The PG licence/trademark text applies to their packaging, so strip their header/footer (we'd do that anyway; it's boilerplate) | `.txt` | Old-fashioned English, but clean and unambiguous legally. PG asks bulk users **not to crawl the website** but to use a mirror (rsync) or their "harvest" endpoint with delays. |
| **Your own Python's source code** | PSF licence (permissive) | `.py` | Already on your disk, so no download needed. Small (~50 MB), but a clean "code" category. We'd add `.py` support to the ingest (one-line change). |

`pyarrow` was approved (2026-10-23) for this. My recommendation: **FineWeb-Edu (sample) as the base, plus Wikipedia and a bit of
Gutenberg and code for variety.** That means saying yes to `pyarrow`. The alternative,
writing our own Parquet reader, is possible but a big detour (Parquet uses
Snappy/Zstd compression and a complex columnar layout).

## Stage 2a: the "general mix" for the scaling ladder (2026-10-24)

Goal: a 22M / 64M / 101M model ladder (`configs/mix-*.toml`) on the same data, to see
how size changes general knowledge, Python, math and sports. All sources are on
Hugging Face as Parquet (read with `pyarrow`), and the owner downloads them. Sizes are
from the dataset cards and file listings as found on 2026-10-24; check each card
before downloading.

| Source (HF dataset) | What it adds | Licence | What we take |
|---|---|---|---|
| `HuggingFaceFW/fineweb-edu`, folder `sample/10BT` | Educational web pages: the general-knowledge backbone. The 10BT sample is 14 Parquet files, ~2.15 GB each (~28.5 GB, ~10B GPT-2 tokens) | ODC-By 1.0 + Common Crawl terms of use | 2 files, cap 3,000 MB of text (40%) |
| `HuggingFaceTB/smollm-corpus`, folder `cosmopedia-v2` | Synthetic textbooks, how-tos and stories written by Mixtral-8x7B-Instruct for clarity, made to train *small* models. 104 files of ~1.18 GB, 39M documents | ODC-By (dataset); generated by an Apache-2.0 model | 1 file, cap 1,100 MB (15%) |
| `wikimedia/wikipedia`, folder `20231101.en` | Encyclopedic facts: people, places, history, sports results. 6.4M articles, ~11 GB of Parquet | CC BY-SA 3.0 + GFDL (share-alike: credit Wikipedia if you redistribute text) | ~1 GB of files, cap 900 MB (12%) |
| `Avelina/python-edu-cleaned` | "Educational" Python files from The Stack (SmolLM's Python-Edu), with the code included. (The original `smollm-corpus/python-edu` only has IDs; the code must be fetched from Software Heritage's S3, which we avoid.) 7.68M files, ~6 GB | ODC-By | ~1.5 GB of files, cap 1,100 MB (15%) |
| `HuggingFaceTB/finemath`, subset `finemath-4plus` | Step-by-step math explanations from the web, filtered by an LLM classifier. ~9.6B tokens, 6.7M documents | ODC-By | ~1 GB of files, cap 750 MB (10%) |
| `Chrisneverdie/OnlySports_Dataset` (optional) | Sports pages pulled out of FineWeb by a sports classifier (OnlySportsLM paper, arXiv 2409.00286). ~600B tokens in all; we take a sliver | The project is **CC BY-NC-SA 4.0** (non-commercial, share-alike); the card's own licence field is empty. Fine for a personal, non-commercial lab; don't use it if the models might ever be used commercially | ~1 GB of files, cap 600 MB (8%) |

Without OnlySports, sports still appear in Wikipedia and FineWeb-Edu, just less.

Proportions (by text size) are set with the `path@MB` caps of `sleuth tokenizer` and
`sleuth shard`, and `meta.json` / the shard log report the actual mix. Total ~7.5 GB of
text ≈ 1.7B tokens with a 32k vocabulary: enough that even `mix-100m` (1.57B tokens)
never repeats data. For comparison, SmolLM2's mature recipe was roughly 60% web,
~10% each of code and math, plus synthetic textbooks.

Deliberately *not* in training: GSM8K and similar benchmark sets. They stay clean for
evaluation (training on a test set makes its score meaningless).

## Stage 3: fine-tuning and memory (downloaded 2026-10-25, approved)

For chat SFT (PLAN §4.6, milestone M11a) and the memory experiments (M11b). Stored in
**`data/finetune/<name>/`**, apart from the pretraining text in `data/raw/`, so `sleuth shard`
can't pick them up by accident. Git ignores both.

| Folder | Source (Hugging Face) | Licence | Contents |
|---|---|---|---|
| `memgpt-traces/` | MemGPT/function-call-traces | Apache-2.0 | 1,394 multi-session chat and document-QA agent traces with real `core_memory_*`, `archival_memory_*` and `conversation_search` calls, plus "no functions" variants |
| `hermes-fc-v1/` | NousResearch/hermes-function-calling-v1 | Apache-2.0 | 11,578 examples: single- and multi-turn function calling, Glaive 5k, JSON mode (`conversations`, `tools`) |
| `when2call/` | nvidia/When2Call | **CC BY 4.0** (attribution required) | 15,000 SFT + 9,000 preference training examples (`tools`, `messages`); 3,652 multiple-choice + 300 LLM-judge test items |
| `longmemeval/` | xiaowu0162/longmemeval | MIT | 500 questions, as `oracle` (15 MB), `s` (278 MB) and `m` (2.7 GB; can be deleted to save space) |

Obligations and caveats:
- **When2Call (CC BY 4.0)**: anything we publish that uses it (a model, a report, derived
  data) must credit NVIDIA's When2Call dataset and link the licence.
- **LongMemEval (MIT)**: keep its copyright and licence notice if we ever redistribute it.
- **Model-generated text**: Hermes (including the Glaive examples) and When2Call were written
  largely by other models, like Cosmopedia in Stage 2a. Their style and mistakes come with them,
  and each upstream model's terms may apply to what was generated: fine for local research,
  but check them before publishing a model trained on this data.
- When2Call's test splits stay out of training: they are our SFT evaluation.

Considered and not added: Salesforce xLAM-60k (needs accepting terms and logging in),
APIGen-MT-5k (non-commercial licence), BEAM (share-alike), Glaive v2, ToolACE and
Toucan-1.5M (fine, but larger; can be added later if SFT needs more data).
